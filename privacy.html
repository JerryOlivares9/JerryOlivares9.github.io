Information & control

Privacy policy.

Effective October 17, 2026

EDITH Mail is the Gmail integration of EDITH, a personal-use assistant operated by Jerry. This policy covers EDITH Mail, its authorized Gmail connection, and this public information website. EDITH is not offered for public account registration.

1. Information EDITH accesses

With the Google account owner’s authorization, EDITH uses the Gmail API to access mailbox identity, message and thread identifiers, headers such as sender, recipients, subject and dates, message bodies, labels, and supported attachments. EDITH also processes the owner’s requests and context needed to answer them.

The Gmail connection uses gmail.readonly. It does not permit EDITH to send or modify email. When incoming-mail monitoring is enabled, Google Cloud Pub/Sub carries a mailbox address and change-history reference; EDITH then retrieves the relevant email through the Gmail API. This monitoring feature is currently being tested separately.

2. How information is used

EDITH uses this information to find messages, summarize email, read supported attachments, answer questions, preserve source references for follow-up requests, and support actions the owner has authorized. Enabled proactive features may evaluate incoming email and prepare notifications or reminder actions.

Google user data is used for these personal-assistant features, not sold or used for advertising, profiling for credit decisions, or training general-purpose AI models. EDITH’s use and transfer of Google user data must comply with the Google API Services User Data Policy, including its Limited Use requirements.

3. Local and cloud processing

Some processing runs locally on the owner’s computer, including the local Gemma model used in incoming-email screening tests. Other tasks use OpenAI’s API. Depending on the request, OpenAI may receive relevant message text, metadata, attachment text or rendered attachment images, task context, and tool results to interpret information or generate a response.

When notifications are enabled, notification content may pass through Apple’s push-notification service and appear on the owner’s configured devices. Google provides mailbox access and, when enabled, change notifications. These providers process data under their applicable service terms and retention practices. Cloud processing is not a claim that all email data stays on the local computer.

EDITH does not publish mailbox data to this website. Routine human review of private email by other people is not part of the feature. Any necessary support access must be authorized by the owner or otherwise permitted by Google’s Limited Use rules.

4. Storage and security

OAuth credentials are stored outside the public website and source repository, protected for the Windows user. Mail execution recovery snapshots are also encrypted for that user. EDITH uses HTTPS for Google and OpenAI API connections and binds mailbox access to the authorized profile.

Local conversation, task, model-execution and result records can contain selected email content, derived summaries, source references and attachment material. Not every local record has the same encryption or retention policy. These records are distinct from ordinary timing logs. No system can guarantee absolute security.

5. Retention and deletion

Temporary recovery snapshots become ineligible after 24 hours and are cleared during subsequent mail use. This is not a 24-hour deletion promise for all email-derived data: conversations, saved results, execution records and reminders may persist until the owner removes them through the relevant controls or requests cleanup.

Revoking Google access prevents further authorized Gmail retrieval but does not automatically erase existing local records or data already processed by providers. The owner can request deletion of stored credentials and local email-derived records at the contact address below. Backups, underlying storage and third-party retention can affect when every copy is removed. Deleting EDITH’s local data does not delete the original messages in Gmail.

6. Your controls

You can remove EDITH’s authorization in Google Account connections, disable enabled email features, and manage saved records in EDITH. For access, correction, deletion or other privacy questions, contact jerryolivares9@gmail.com.

7. This public website

This site is a static information site hosted by GitHub Pages. It contains no Gmail sign-in form, mailbox viewer, analytics scripts, advertising, or application cookies. GitHub may collect technical request data, including IP addresses, when serving the site, as described in the GitHub Privacy Statement.

If you contact the operator by email, your address and message will be used to respond and handle your request.

8. Changes and contact

This page will be updated when EDITH’s relevant data practices change. The effective date above identifies this version. Operator and support contact: Jerry, jerryolivares9@gmail.com.
